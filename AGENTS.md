# DreamaticMake

Use Pi as a pinned upstream SDK. Never copy its runtime internals.
Product agents live in .pi/agents; these are application personas, not instructions to the coding assistant.
Keep approval decisions exclusively on authenticated application routes, never in agent tools.
Engineering geometry, BOM and firmware share versioned contracts. Never claim compiled or manufactured success without execution evidence.
Run npm run check, npm test and npm run build for application changes. CAD worker changes require a real geometry smoke test when the toolchain is available.
Do not read or export .env secrets. Runtime data lives in ignored workspace/.
