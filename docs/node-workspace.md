# 节点工作台（本地首版）

> 此文记录最初的阶段节点网格。2026-10-23 已按用户反馈改为真正的端口式数据流画布，当前行为、功能—硬件统筹与预览见 [端口式工作流](port-workflow.md)。下方验证状态是当时记录，不能当作新版的最新检查结果。

进入项目后默认显示节点工作台。八个节点对应项目已有的八个阶段，使用真实项目状态、草稿与审阅信息；节点点击只切换查看内容。实线表示前一个流程阶段已确认，虚线表示仍等待确认。这里画的是阶段推进关系，不能理解为项目数据仅来自紧邻的一个节点。

默认的设计视图显示简短结果与待办；高级视图增加每个节点的输入、作者和审阅入口。输入页列出已确认的上游阶段，作者页展示阶段职责概览，审阅页展示实际审阅和当前输入哈希。职责概览不是新的角色提示词。

问题卡、方案选择与确认继续使用原来的受校验接口。确认卡在节点面板和对话区之间只挂载一份，避免重复倒计时。节点面板折叠大段说明和审阅文字；完整内容仍可通过“阶段详情”访问。项目对话可从右上角展开。

没有改动智能体提示词、全局协议、阶段执行和审批条件。原有第一阶段新旧提示词的选择保持不变。
