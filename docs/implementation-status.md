# 实现与验收状态

日期：2026-10-18 · 应用版本：0.1.0

## 已实现

- 独立智能体 MD 标准定义、运行时读取与 Schema 校验、工具白名单、当前阶段路由和交接。
- Pi 1.3.0 SDK 会话、模型配置、流式事件、会话文件、取消、运行中补充指令、有界重试和调用上限。
- 八阶段状态机、草稿、独立审阅、用户审批、版本/输入哈希、产物校验、幂等确认和下游失效。
- 独立项目目录 `workspace/<项目ID>/`、可配置工作根目录、旧目录兼容迁移、项目部件快照及测量隔离。
- 本地项目管理、SSE 重连、服务重启中断恢复、设置、工具链诊断、附件和交付包。
- 左上角品牌下拉菜单与 Dreamatic 样式的四模块 Settings（推理模型、图像模型、CAD、系统）；图像服务的地址、密钥和模型可独立配置，兼容旧视觉模型变量。
- Dreamatic 风格工作台、Codex 风格输入区、问题卡、方案卡、审批卡、参数/结构编辑器、3D 预览和文本文件预览。
- 文生候选参数与图生候选参数，确认后生成上下壳、矩形开孔、螺柱与部件参考包络。
- 真实 STEP/STL 导出、实体/体积/回读/闭合检查及部件空间碰撞检查；盖板定位边、总高/干涉检查与打印朝向已验证。
- 官方资料网页抓取、目录候选导入、Pico 尺寸实测补充，资料不完整时阻止硬件确认。
- Pico Arduino Mbed 固件实际编译、固定核心依赖、工具链版本清单和固件下载。
- macOS 默认拒绝的执行隔离，验证了工作进程无法读取任务外的私有测试文件，也不能向任务外写入。

## 已执行的验证

1. TypeScript 类型检查、生产构建。
2. 审批、角色与版本限制、几何缺口强制阻塞、上游重开与旧审阅失效、幂等、候选/问答、文件篡改、并发事件、恢复、秘密字段和 HTTP API 自动测试。
3. 本地模型夹具驱动 Pi 的真实 SDK 工具协议，验证协调者、作者和独立审阅者的权限与等待状态。
4. 真实 CAD 生成、STEP 回读、STL 网格闭合、带开孔/支柱/部件的装配，以及碰撞反例拒绝。
5. 真实 Pico 固件编译通过；没有连接或烧录实物设备。
6. 完整八阶段执行链：确定性模型夹具 + 真实 CAD/固件工作进程，八次独立审阅与用户确认。
7. 浏览器界面测试：创建项目、阶段预览、方案/审批卡、文生参数、CAD 生成、设置和移动布局。
