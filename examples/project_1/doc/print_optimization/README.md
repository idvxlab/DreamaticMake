# 09 · 打印件优化

版本：v0.1，2026-11-06。用户选择PLA、0.4mm喷嘴、0.2mm层高。流程：`doc/tasks/index.json`。本阶段完成CAD工艺修订、逐件打印姿态与包络检查，没有运行切片或实物打印。

## 参数与几何修订

成形空间暂按220×220×250mm假设，实际打印机未指定；45°悬空角、1.2mm最小特征目标、4道壁与20%填充均为切片起点，不是已验证工艺。材料物性未知，未做温升或强度承诺。

- 壳壁2.4mm；定位唇边约1.6mm，滑动导向与定位唇每侧留0.3mm。
- 键帽有1.2mm止退肩、0.4mm实体限位；开槽底部为整个按压行程留空间，闭合盖避让安装耳与载板螺钉柱。
- 后盖沉头孔为45°斜面，闭合盖孔口有0.3mm入口锥面，减少突变悬垂和装配刮边。
- 电池用可拆刚性压桥保留上方余量；不使用需要长期弯曲的PLA薄弹片。
- 屏框中央和盖板定位唇加入真实避让槽；装配干涉修复已反映到STEP，而非只在说明里标注。

## 打印姿态与交付

[plan-v0.1.json](plan-v0.1.json) 记录12种打印定义的数量、固定版本、局部到打印机的build_pose与支撑建议，覆盖25个装配打印实例。打印机+Z为成形方向，**未用摆盘姿态覆盖装配位姿**。

前壳以前脸朝下、后盖以背面朝下；压框/闭合盖以大平面朝下；电池压桥倒置；键帽大面朝下；载板保持架按记录姿态放置。每种元件的 `assets/print.step` 已应用打印姿态并平移到第一象限和Z=0，`part.step` 保留原生局部基准。

所有单件的BRep包络已检查落入假设成形空间。这不是整批摆盘，也不代表一板能排下全部件。键帽止退肩、按键开口上沿、RTC托座和保持架立柱内侧要在切片器中检查局部支撑；支撑不能破坏滑动面、PCB支承面或孔口。

可从 [STEP打包文件](assets/project_2-step-v0.1.zip) 取得12个原生姿态STEP、12个打印姿态STEP及打印件装配STEP。原生包另含STL，便于切片器导入。

建议先打印一套小按键组件验证配合，修整孔口后再试装。实际收缩、首层扩张、孔径误差、支撑、用料与打印时长尚未知，需真实切片和打印后补记录。
