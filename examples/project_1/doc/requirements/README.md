# 01 · 需求与功能

版本：`0.4`。已补充元件CAD、STEP、装配和PLA工艺要求。依据：[SRC-01—SRC-08](source.md)，流程：`doc/tasks/index.json`。功能说明v0.3；工程与实物验证状态分别记录。

## 使用场景

放在床头，日常查看时间、设置闹铃；到点发声提醒，醒来后可通过实体按键停止或延后提醒；夜间降低显示亮度。具体观察距离、摆放高度和睡眠时间尚未提供。

本轮以本地操作的数字闹钟为候选方案。联网、手机应用、语音、天气和多闹铃不列入当前核心范围；这属于范围建议，用户提出时重新评估。

## 第一版行为建议

以下均为候选默认值，尚未经用户确认，也不是已实现的能力。

- 24 小时制，显示时和分；每天一个闹铃。
- 顶部大按键用于贪睡，设置与停止操作有明确区别；按键数量在外观阶段确定。
- 贪睡延后 5 min，连续最多 3 次；超过上限后停止当次提醒，保留次日闹铃。
- 单次响铃最多 2 min；未操作则停止当次提醒，避免无限持续响铃。
- 夜间暂拟 22:00—07:00 调暗，保留手动亮度切换；不预设必须使用光传感器。
- 采用整机备用电池；RTC 保时电池不能代替它。电量耗尽后不承诺继续显示和响铃，恢复时检查时间有效性。

以上默认值只供下一轮讨论。尺寸、电源、预算、精度、亮度和声压没有被指定为确定值。

## 验收场景

| 场景 | 操作与预期 | 对应需求 |
| --- | --- | --- |
| T-01 正常使用 | 上电、校时、设置下一分钟闹铃、启用；到点提醒，停止后本次不再响 | R-02/03/04/07 |
| T-02 贪睡 | 响铃时按贪睡；立即静音，进入等待，经过设定时长再响；到次数上限按策略退出 | R-05/07 |
| T-03 夜间 | 跨越夜间开始/结束时间并手动切换亮度；显示仍可读，亮度模式有确定优先级 | R-02/06 |
| T-04 设置边界 | 设置 23:59 与 00:00、取消修改、保持不操作；不出现非法时间或被吞掉的操作 | R-03/04 |
| T-05 跨日与设时 | 贪睡跨午夜、响铃中校时、把时间调回触发时刻；核对不重复误响 | R-04/05 |
| T-06 电源切换与耗尽 | 显示、响铃、贪睡期间分别拔插外接电源，整机保持原状态；再测试主电池耗尽后的失效与恢复行为，记录续航 | R-08/12 |
| T-07 实物交互 | 约定距离观察、暗处辨认按键、床头单手操作；记录误按、滑移与倾倒 | R-01/02/09 |

这些场景是测试计划。精度应另做持续计时对比，声音应按确定的距离与仪器测量；目前没有测试结果。
