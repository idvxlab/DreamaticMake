## 闹铃状态机

闹铃开关、显示亮度与设置界面分别维护，避免把夜间调暗误当作关闭闹铃。

| 当前状态 | 事件 | 下一状态与动作 |
| --- | --- | --- |
| 未启用 | 用户启用且时间有效 | 待触发，显示启用标志 |
| 待触发 | 首次到达当日设定时刻 | 响铃，记录本次触发标识 |
| 响铃 | 贪睡且未超上限 | 贪睡等待，静音并开始延后计时 |
| 贪睡等待 | 延后计时到期 | 响铃，沿用同次提醒的次数记录 |
| 响铃/贪睡等待 | 停止本次 | 待触发，清除本次贪睡，等待下一个有效日程 |
| 响铃 | 响铃超时或贪睡上限策略结束 | 待触发，停止本次，不补触发已错过的时刻 |
| 任意 | 关闭闹铃 | 未启用，清除本次提醒及等待 |
| 任意 | 时间无效 | 禁止时间触发，显示需校时；校时后重新计算下一次日程 |

候选实现规则：

- 用独立的经过时间计时控制贪睡和响铃超时，校时不能缩短或延长正在运行的倒计时。
- 同一日程实例只触发一次；向后校时不能反复触发。校时之后重新安排下一次未来日程，错过时刻不补响。
- 设置过程保持原有效时间继续计时；确认时统一提交新设置，取消不保存。响铃时先处理停止/贪睡，不把同一按键事件透传到设置界面。
- 手动亮度覆盖当前自动档，下一次夜间时段切换恢复自动；该优先级为待确认建议。
- 拔掉外接电源时，由主备用电池维持整条逻辑电源轨，显示、响铃和贪睡继续原状态。不能把备用外设接到断电后消失的 USB VBUS。
- 主电池耗尽后不恢复旧贪睡倒计时，不补响错过的闹铃；重上电后检查 RTC 振荡停止/时间有效状态，未知时间先校时。设置参数持久化策略在固件阶段落实。
