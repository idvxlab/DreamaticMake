## 建议装配顺序

1. 先试配一套小键帽、导向座、闭合盖和载板保持架，验证0.3mm侧隙、0.4mm限位及实际开关行程，必要时调整后再打印整壳。
2. 将键帽从导向座开放侧装入，使止退肩位于导槽下方；闭合盖用两枚M2×6固定。安装壳体前即可完成该步骤。
3. 将已焊开关的12×12mm载板从下方放入导向座；底部保持架以四枚M2×4固定。底部开口留给THT脚和焊线，禁止把载板永久封在壳内。焊盘及脚位须先核对，未提供Gerber。
4. 五套按键组件各以两枚M2×4固定到相应壳体；顶部大键、侧面停止键和背面三键保持明确区分。
5. OLED对准前窗，用合适柔性垫与屏框固定，四枚M2×8拧到定位即可。不要依赖压玻璃或未知元件表面来取得夹紧力。
6. 托架放入前壳，用四枚M2×3固定。主控用边缘支承、垫片与扎带定位；RTC位于托座，电池加软垫后装压桥，两枚M2×5固定。电子模块孔位/器件净空未测，不把托座视为厂家安装接口。
7. 压电放入后盖定位环，以合适柔性胶垫固定并对准声孔。按电路阶段网络接线，留可拆线束余量；外部USB接口先做实际插拔对位。
8. 接电验证按键、显示、声音及断电切换，再收拢线束，确认不压线后合后盖，用四枚M2.5×8沉头自攻螺钉固定。

## 验证与限制

已执行当前打印件之间、打印件与10个名义电子包络的静态BRep体积相交检查，及15个按压姿态检查。零非预期穿透只针对这些输入，不包括真实电子元件、接头、焊点、螺钉实体、工具包络或连续装配路径。

螺钉孔是PLA原型设计：M2试配底孔1.8mm、M2.5试配底孔2.0mm；不声称已验证自攻保持力。开盖时先断开电源并避免拉扯电池线。实际寿命、充电温升、夹持力和按钮不卡滞均待实测。
