# 07 · 运动深化

版本：v0.1，2026-11-06。依据本轮CAD和当前空间位姿，按 `doc/tasks/index.json` 建立键帽运动与整机随动。工程数据仍放 `design/motion.json`，没有增加独立运动私有格式。

## 关系与行程

以 `case_front/body` 为根，固定后盖、托架和屏框；托架固定电子件与压桥；后盖固定压电及后部按键组件。导向座固定开关、闭合盖与载板保持架，键帽相对导向座滑动。共36条关系：31条fixed、5条prismatic；每个物理刚体只有一个父节点。

`press/snooze`、`press/stop`、`press/set`、`press/minus`、`press/plus` 均沿导向座局部 −Z 按入，范围0—0.0004m，初值0。键帽限位脚与导向座实体留0.4mm间距，在终点接触；不是只在JSON中写一个行程数字。

名义接触前间隙0.15mm，压到终点时开关包络被侵入约0.25mm。这是待试配的设计假设，不代表所购开关已证明可承受该行程；试装后通过限位垫片、柱长或行程参数调整。回弹来自实体开关，未设计PLA弹性铰链，也未模拟弹簧或触感。

## 实际检查

[validation-v0.1.json](validation-v0.1.json) 记录五键各0、0.2、0.4mm的15个离散姿态。对每个姿态，执行运动学并对实际打印BRep做布尔相交检查；本键开关的名义包络接触单独记录，其他打印件及其他名义硬件不允许实体穿透。

整机根节点平移+10mm的随动检查见 [assembly-v0.1.json](../assembly_detail/assembly-v0.1.json)：37个物理刚体都随动，外部抽象USB电源不作为物理刚体。此检查覆盖理想刚体约束，没有覆盖连续扫掠、摩擦、装配变形、回弹力、寿命或电气触发。
